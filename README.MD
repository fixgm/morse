1. Проработка структуры проекта
```txt
    MorseApp - > service -> core
    java
        \com.my_project.morse
            \config - этого нет (в нашем проекте)
            \core - ядро, основная логика (азбука, алгоритм)
            \controller - этого нет (в нашем проекте)
            \exception - исключения
            \model - этого нет (в нашем проекте)
            \service - слой сервисов, вспомогательная работа вокруг ядра
            \repository - этого нет (в нашем проекте)
            \util - этого нет (в нашем проекте)
            MorseApp.java
       
```
